# Sistem Tracking Berkas Kredit - BPR Sahabat Sejati

Aplikasi berbasis web untuk melacak dan mengelola alur pengajuan berkas kredit di BPR Sahabat Sejati.

## Fitur Utama

- Tracking status alur berkas kredit secara real-time.
- Manajemen pengguna dan autentikasi hak akses (Role Base).
- Laporan dan rekapitulasi durasi penanganan tiap tahap.

## Persyaratan Sistem

- PHP >= 8.2
- Composer
- Node.js & NPM
- MySQL / MariaDB

## Cara Instalasi

1. Clone repositori:
    ```bash
    git clone [https://github.com/zxamin212/trackingbprss.git](https://github.com/zxamin212/trackingbprss.git)
    cd trackingbprss
    ```
